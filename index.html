From shortlist to parcel

DgoBuy product links and seller checks

When browsing DgoBuy finds, save the original seller listing along with the product model code, colour option and selected size. If a listing has several variants, record the exact variant name and its price in CNY. Add the date you checked it so you can spot changes before ordering.

Compare two sellers using the same variant. Check whether the item is in stock, whether domestic shipping is included and how the seller handles exchanges.

DgoBuy shoe finds and clothing fit

Use foot length in centimetres and the seller’s shoe size chart to narrow down your size. For a sneaker QC check, compare the box label and the size tags on both shoes. Check insole length only against a measurement taken the same way.

For clothing, compare a T-shirt’s laid-flat chest width and body length against a shirt you own. Check shoulder width and sleeve length for jackets, waist and inseam for trousers, head circumference for caps and inner circumference for bracelets.

DgoBuy QC photos and warehouse checks

Review front, back and label photos before approving dispatch. For dark fabrics, ask for a photo in neutral light if the colour is unclear. If fit depends on a few centimetres, ask for a ruler photo showing both ends of the measurement.

Look for uneven seams, damaged hardware and missing accessories. If anything differs from the listing, check the return window while the item is still at the warehouse.

DgoBuy shipping guide and landed cost

Keep the item price, currency conversion, payment fees, domestic delivery and international freight on separate lines. Include any applicable destination taxes and duties when you compare the total landed cost.

For parcel consolidation, ask for the packed dimensions and actual parcel weight. If the carrier uses volumetric weight, check which figure determines the quote. Compare the shipping options available to your postcode and check any restrictions for your items.

Frequently asked questions

What is a DgoBuy spreadsheet?

A DgoBuy spreadsheet is a shopping reference for organizing product links and comparing items before ordering. This guide provides category shortcuts and explains what to verify on the seller listing.

What should I do if a product link is dead?

Search using the seller name, model code or a clear product image. Compare the new listing’s measurements, material and colour options before replacing the old link.

Can warehouse QC photos verify authenticity?

Warehouse QC photos help you check visible condition, size tags and colour. For branded goods, use a trusted seller and independently verify provenance.

How do I estimate international shipping costs?

Get a shipping quote for your destination using packed dimensions and actual weight. Check the carrier’s billable weight rules and include any applicable fees, taxes and duties in your estimate.
